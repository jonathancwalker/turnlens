# Portfolio documentation

## Project brief

An early-stage browser companion for adults reviewing their own AI conversations. It links context-aware observations to exact transcript evidence and aims to surface useful signals without alert fatigue. The user originated the concept, specified the browser sidebar and live highlighting, and is directing the UX iteration. The work is currently research and design; no live detector or extension has been built.
